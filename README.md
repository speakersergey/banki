# Коллекция банок

Веб-приложение для учёта коллекции банок газировки. Работает в браузере на телефоне и компьютере, его можно установить как обычное приложение. После первого открытия работает и без интернета.

Каждый пользователь ведёт свою коллекцию: данные и фото хранятся в браузере на его устройстве. Регистрация не нужна.

## Что умеет

- фотографировать банку и по шагам спрашивать: название, страну, вкус, событие, объём, высоту, дату и примечания;
- показывать список с фото, страной и вкусом, а все поля — в карточке банки;
- искать и фильтровать по стране, вкусу, событию и высоте, сортировать;
- загружать коллекцию из Excel и выгружать её обратно в Excel;
- сохранять резервную копию с фото в один файл и восстанавливать из неё (так же коллекция переносится на другое устройство).

## Как выложить в интернет (GitHub Pages, бесплатно)

1. Зарегистрируйтесь на https://github.com.
2. Нажмите «+» → **New repository**. Название, например, `banki`. Выберите **Public** и нажмите **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file**.
4. Перетащите в окно **все файлы** этой папки. Сам архив загружать не нужно, только то, что внутри.
5. Внизу нажмите **Commit changes**.
6. Откройте **Settings** → **Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**, ветку **main** и папку **/(root)**, затем **Save**.
7. Через 1–2 минуты приложение появится по адресу `https://ВАШ-ЛОГИН.github.io/banki/`. Эту ссылку можно отправлять друзьям.

## Как установить на телефон

- **iPhone:** откройте ссылку в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** откройте ссылку в Chrome → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
- **Компьютер:** в Chrome или Edge нажмите значок установки в адресной строке.

## Как перенести свою таблицу

Меню (⋯) → **Загрузить из Excel** и выберите файл. Нужны заголовки колонок: номер, название, страна, примечания, вкус, событие, объём, высота, год.

## Как обновить приложение

Загрузите изменённые файлы в репозиторий так же, через **Add file → Upload files**. Если менялся `app.js` или `style.css`, поменяйте в `sw.js` строку `const VERSION = "cans-v1"` на `cans-v2` (и так далее). Тогда у пользователей подтянется новая версия.

## Важно

- Коллекция живёт в браузере. Если очистить данные сайта или удалить приложение, она пропадёт. Время от времени сохраняйте резервную копию через меню.
- В приватном режиме браузера данные не сохраняются.
